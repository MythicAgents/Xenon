## Summary

Xenon is a Cobalt Strike-like Windows agent built for the Mythic C2 framework. The agent was written in C with the goal of learning more about how C2 agents (such as Cobalt Strike's Beacon) work.

If you would like to contribute to the project, please work off of the **next version branch** (named like "v0.0.7") as merges will go into that.

If you'd like your PRs to be merged then:
- Do not submit completely vibe-coded additions
- Follow the existing programming styling
- Keep PRs < 1k lines of code focused on single features
- C is inherently prone to memory bugs, do not refactor large portions of code unless explicitly stating why
