## Summary
Disconnect from a linked peer-to-peer agent. The linked agent will continue running but will no longer relay tasking through this agent.

### Arguments

#### display id
The Display ID of the linked agent as shown in the Mythic UI.

## Usage
```
unlink <display id>
```

Example
```
unlink 3
```
