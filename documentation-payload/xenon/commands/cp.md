## Summary
Copy a file from one location to another.

### Arguments

#### source
The path to the source file.

#### destination
The path to write the copy to.

## Usage
```
cp <source> <destination>
```

Example
```
cp C:\Users\bob\secret.txt C:\Windows\Temp\secret.txt
```
